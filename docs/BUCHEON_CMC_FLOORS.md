## 건물 구성 — 3개 관

병원 공식 안내는 **성모관 / 성가정관 / 성심관** 3개 건물로 나뉜다.
(정책제안서에서 지적한 "건물 선택 → 검색 → 약도 확인" 다단계 UX의 원인이 이 구조다.)

### 성모관 — 외래·검사의 중심. **프로토타입 대상 1순위**

| 층 | 부서 |
|---|---|
| B1 | 국제진료센터, 방사선종양학과, 핵의학과(PET/CT실) |
| 1F | 영상의학팀(일반촬영실, 혈관조영실, CT실, MRI실), 응급의료센터, 진료협력센터, **채혈실**, 초음파실 |
| 2F | **내과**, 당뇨병센터, 비뇨의학과, 산부인과, 소아청소년과, 신경과, 신경외과, 정신건강의학과, **정형외과**, 주사실, 치과, 혈관센터 |
| 3F | 인공신장실(복막투석실) |
| 4F | 이비인후과, 심장검사실 |

### 성가정관

| 층 | 부서 |
|---|---|
| 1F | 종합검진센터(일반건강검진실) |
| 2F | 기능검사실(뇌파, 전정기능), 성형외과, 재활의학과(검사실, 성인·소아작업실, 연하장애클리닉), 안센터, 피부과 |
| 4F | 당일수술센터(DSC), 항암주사실, 옥소치료실 |

### 성심관

| 층 | 부서 |
|---|---|
| 2F | 여성센터·유방암센터(유방촬영실, 유방초음파실), 호흡기폐암센터(폐기능검사실) |
| 3F | 내시경센터(기관지내시경실, 내시경실, 치료내시경실), 소화기센터·외과(외과초음파실), 장기이식센터 |

## ★ 핵심 발견: 예선덱 시연 시나리오가 성모관 1F–2F 안에서 전부 성립한다

예선덱 p7 / 본선덱 p8의 AI 변환 예시:

> "내과 외래 접수 후 채혈실 방문, 영상의학과 흉부 X-ray 촬영 후 내과 외래 앞 대기"

실제 부천성모 배치에 대입하면:

| 단계 | 실제 위치 |
|---|---|
| 내과 외래 접수 | 성모관 **2F** 내과 |
| 채혈실 | 성모관 **1F** |
| 흉부 X-ray (영상의학팀 일반촬영실) | 성모관 **1F** |
| 내과 외래 앞 대기 | 성모관 **2F** |

**즉 시연 시나리오는 성모관 2개 층만 있으면 완결된다.**
브리핑 §7의 "3개 층 40~60 노드" 예산보다도 작다. 범위 축소 기회.

전체 환자 여정으로 확장해도 동일 건물 안:
`1F 원무 접수 → 2F 내과 → 1F 채혈실 → 1F 일반촬영실 → 2F 내과 대기 → 1F 수납 → 약국`

→ **결정: 프로토타입 1차 범위는 성모관 1F + 2F.** B1·3F·4F 및 성가정관·성심관은
"동일 스키마로 확장 예정"으로 처리한다.

## 현재 프로토타입 목데이터와의 대응

| 현재 (가상) | 부천성모 (실제) | 비고 |
|---|---|---|
| 2층 정형외과 205번방 | 성모관 2F 정형외과 | **층이 우연히 일치** |
| 4층 CT실 | 성모관 **1F** CT실 | 층 변경 필요 |
| 4층 엑스레이실 | 성모관 **1F** 일반촬영실 | 층 + 명칭 변경 |
| 1층 원무과 / 약국 | 실측 필요 | 홈페이지에 미기재 |
| 3층 신경외과 | 성모관 **2F** 신경외과 | 층 변경 |

현재 목데이터는 검사실을 4층에 몰아뒀지만, **실제 부천성모는 영상검사가 전부 1층**이다.
층간 이동이 줄어드는 방향이라 경로가 단순해진다.

## 답사에서 반드시 채워야 할 공백

홈페이지에 **없는** 정보 = 전부 현장답사 항목:

- [ ] **원무과·수납 창구 위치** (1F 어디인지)
- [ ] **약국 위치** (원내인지 원외인지)
- [ ] **초진창구 위치** — 브리핑 §3.1이 동선 시작점으로 지목한 곳
- [ ] **엘리베이터·계단·에스컬레이터 위치와 개수** (성모관 1F↔2F)
- [ ] **복도 구조** — 현재 프로토타입은 "복도 1개 + 위아래 방 2줄"을 가정. 실제와 다르면
      `HospitalFloorMap`의 `getCorridorY` 전제가 깨진다
- [ ] **성모관 ↔ 성가정관 ↔ 성심관 연결 통로** (몇 층에서 이어지는지)
- [ ] 구간별 거리 (걸음 수 추정)
- [ ] **실제 접수증 실물** — QR/바코드 유무 (브리핑 §4 리스크)
- [ ] 각 층 사진 (충실성 참여도 15점 증빙)

## 정정 사항

병원 공식 홈페이지 하단 표기 주소:

> **경기도 부천시 원미구 소사로 327 (14647)**

브리핑 §3.1에는 "부천시 **소사구** 소사로 327 (소사동)"으로 적혀 있다. 공식 표기는 **원미구**다.
발표자료·정책제안서의 주소 표기를 원미구로 통일할 것.

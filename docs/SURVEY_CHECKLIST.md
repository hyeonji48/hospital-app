# 현장답사 체크리스트 — 부천성모병원 성모관

> **2026-08-24 갱신.** 병원 공식 평면도를 확보하면서 **재야 할 것이 대폭 줄었다.**
> 좌표·배치·방 순서는 도면에서 옮겼으므로 답사에서 잴 필요가 없다.

## 무엇이 달라졌나

병원 홈페이지 `병원둘러보기`가 층별 평면도 PNG를 제공하고 있었다.
성모관 B1·1F·2F·3F·4F 전부 확보했고, 그 도면대로 `floorPlan.ts` 를 다시 그렸다.

- ❌ ~~복도 걸음 수 측정~~ → 도면이 축척이라 거리 비교는 좌표로 계산된다
- ❌ ~~방 좌우 순서 확인~~ → 도면에 그대로 나와 있다
- ❌ ~~복도 구조 확인~~ → 중앙 코어(엘리베이터 6대 + 계단 2 + 화장실)를 둘러싼 배치임을 확인

## 1. ★ 반드시 확인 — 도면에 없는 것

공식 평면도에 **원무과와 수납창구가 표기되어 있지 않다.** 접수와 수납은 동선의 시작과 끝인데
위치를 모른다. 코드에는 정문 근처로 추정 배치해두고 `estimated: true` 로 표시해뒀다.

| 확인할 것 | 왜 |
|---|---|
| **원무과(접수) 위치** | 동선의 첫 단계. 지금은 추정값 |
| **수납창구 위치** | 동선의 끝에서 두 번째. 지금은 추정값 |
| **안내데스크 위치** | 지금은 추정값 |
| **약국이 건물 안인가 밖인가** | 도면상 1층 왼쪽 아래인데 원내/원외 불명확 |

사진 한 장씩만 찍어오면 된다. 정확한 미터는 필요 없고 **"정문에서 봤을 때 어느 쪽"** 이면 충분하다.

## 2. 엘리베이터 확인

평면도에 **엘리베이터가 6대** 있다. 코드는 "전부 같은 코어에 있고 모든 층에 선다"고 가정한다.

- [ ] 6대가 **모두 모든 층에 서는가?** (일부가 특정 층 전용이면 경로가 달라짐)
- [ ] 외래 환자가 쓰면 안 되는 것(직원용·침대용)이 섞여 있는가?
- [ ] 1층 정문에서 엘리베이터까지 **바로 보이는가**, 아니면 돌아가야 하는가

## 3. 발표용 숫자 (앱과 무관, 하지만 제일 중요)

브리핑 §9의 **"기존 84분 → 51분"** 을 실측값으로 바꿔야 한다.
이건 앱이 아니라 **스톱워치**로 잰다.

- [ ] 접수 → 진료 → 검사 → 수납 → 약국까지 **전체 소요시간**
- [ ] 각 구간 대기시간 (특히 채혈실·수납)
- [ ] 헤매는 데 쓴 시간 (물어보러 간 횟수)

## 4. 앱 실사용 테스트

- [ ] `sample-receipt.html` **인쇄본 3장** 지참
- [ ] NFC 스티커에 **Vercel 주소**가 쓰여 있는지 확인
- [ ] 폰 태그 → 웹 열림 → `체험해 보기` → 끝까지 완주
- [ ] `실제 접수증으로 인식하기` 로 인쇄본 촬영 → AI 인식 결과 확인
- [ ] 틀리게 읽으면 **그 사진을 저장** (프롬프트 개선에 씀)
- [ ] 병원 내부 **통신 신호**가 약한 곳이 있는지 (폴백 동작 확인)

> **실제 환자 접수증은 절대 촬영하지 않는다.** 우리가 만든 샘플만 쓴다.

## 5. 기록물 — 충실성 참여도 15점

- [ ] 각 층 사진 (엘리베이터 코어, 정문, 원무과, 채혈실)
- [ ] 환자들이 실제로 **헤매는 지점** 관찰 메모
- [ ] 원무과 직원 / 안내 봉사자 인터뷰
